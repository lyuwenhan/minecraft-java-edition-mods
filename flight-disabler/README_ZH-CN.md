# Flight Disabler (禁止飞行)

一个轻量级的 **客户端 Fabric 模组**，用于禁用创造飞行和鞘翅飞行，并完全运行于客户端。

## 概述

禁止飞行会阻止本地玩家使用创造飞行和鞘翅飞行。

该模组可以通过按键绑定切换启用或禁用状态。

启用后，创造飞行权限会被强制关闭，鞘翅飞行尝试会被阻止。

## 核心特性

- 禁用创造飞行
- 禁用鞘翅飞行
- 可通过按键绑定切换
- 保存启用或禁用状态到配置文件
- 仅客户端
- 轻量化，对性能影响极小

## 控制

- 按 `B` 切换禁止飞行的启用或禁用状态
- 默认状态为启用

## 支持版本

- Minecraft 26.1.2
- Fabric Loader 0.19.2+
- Fabric API 0.150.0+
- Java 25
