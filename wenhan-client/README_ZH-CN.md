# Wenhan Client (Wenhan 客户端)

Wenhan 客户端是一套由多个独立功能组成的客户端工具合集，旨在改善我的世界中的操作、探索、建造和个性化体验。

## 功能

### 通用

| 功能 | 说明 |
| --- | --- |
| 隐藏密码模式 | 输入受支持的登录和账户命令时，选择关闭隐藏、仅用等长星号隐藏密码内容，或固定显示 8 个星号以同时隐藏密码长度。 |
| 隐藏 Realms | 禁用 Realms 后台检查，并隐藏标题界面的 Minecraft Realms 按钮。 |
| 立即复活 | 跳过死亡界面并立即复活。 |
| 禁止触发方块爆炸 | 禁止在非主世界使用床或稻草床，并禁止在非下界使用重生锚。不阻止挖掘。 |
| 安全丢弃 | 游戏中丢弃受保护物品时，需再按一次丢弃键确认。 |
| 移除镜头碰撞 | 第三人称和第二人称视角保持固定镜头距离，不再因为方块阻挡而缩短。 |
| 穿过方块攻击 | 关闭: 不穿过方块。穿过植被攻击: 可穿过草、花等无碰撞箱的方块攻击。穿过所有方块: 忽略所有方块遮挡，优先选中视线射线上攻击距离内的生物，没有生物时保留普通命中。 |
| 无雾 | 移除水下、岩浆、细雪、失明、黑暗、天气、Boss 和维度地形迷雾、虚空遮罩、低高度天空变黑、群系天空色和液体中的天空变色，并取消视野扭曲。 |
| 持续渲染透明方块 | 持续显示屏障、结构空位和光源方块。 |
| 取消挖掘延迟 | 长按攻击方块时，连续挖掘延迟将逐步降低至 1 tick。 |
| 取消放置延迟 | 长按使用/放置方块时，连续使用延迟将逐步降低至 1 tick。 |
| 稳定挖掘 | 挖掘方块时保持准心指向该方块中心；若当前位置的视线会被阻挡，则不移动鼠标。 |
| 辅助搭路放置 | 手持方块且准心未命中真实方块时，可命中具有选择轮廓的方块向前、后、左、右扩展一格形成的可放置位置。流体不会作为扩展基点，真实方块的命中始终优先。 |
| 液体表面放置 | 手持方块且准心未命中真实方块时: 身处对应液体中可命中接触空气的液体格；不在对应液体中可命中接触该液体的空气格。本功能只补充准心目标，不会阻止其他方式的放置。 |
| 连续放置约束 | 持续按住使用键放置方块时，以首个成功放置的方块为基准约束后续位置。轴向直线模式由第二个方块确定 X、Y 或 Z 轴；水平面模式固定 Y 坐标；垂直平面模式由首次水平偏移确定固定 X 或固定 Z 的平面。准星仅命中视线实际经过且符合约束的可放置位置，包括空气方块。松开使用键后重置本次放置序列。 |
| 玩家高亮模式 | 控制玩家高亮何时生效。 |
| 玩家及路径点信息 HUD | 在 HUD 上显示附近玩家和路径点信息。 |

玩家高亮模式包括 `不开启玩家高亮`、`仅按住玩家列表键时` 和 `一直启用`。HUD 可以显示名称、相对方向、水平距离、生命值和坐标。

示例：

```text
Player867 ↑ 11m ❤ 20.0 (123, 64, -456)
```

### 移动

| 功能 | 说明 |
| --- | --- |
| 客户端飞行 | 在生存和冒险模式中启用飞行。 |
| 禁止创造飞行 | 阻止创造飞行开始，并停止正在进行的创造飞行。 |
| 禁止鞘翅飞行 | 阻止鞘翅飞行开始，并停止正在进行的鞘翅滑翔。 |
| 禁止落地重置飞行 | 创造飞行时碰到地面后不取消当前飞行状态。 |
| Freecam 交互转向 | 使用 Freecam 的交互功能时，让本地玩家朝向交互目标。可选择交互结束后恢复原视角。 |
| 墙壁攀爬 | 仅本地玩家可以攀爬任意方块的墙面。贴墙按住空格或朝墙移动即可向上攀爬。 |
| 鞘翅取消 | 鞘翅滑翔中按跳跃键停止滑翔。 |
| 无跳跃延迟 | 移除跳跃冷却，按住跳跃时可以快速连续跳跃。 |
| 取消悬浮 | 取消本地玩家的悬浮效果。 |
| 取消缓降 | 取消本地玩家的缓降效果。 |
| 无碰撞 | 阻止其他实体推动玩家。 |
| 流体平台 | 允许本地玩家站在水和岩浆表面。下蹲时穿过。 |
| 固体蜘蛛网 | 仅为本地玩家将蜘蛛网设为完整方块碰撞箱，不影响穿过方块攻击的判定。 |
| 虚空地板 | 在主世界 Y=-105、下界和末地 Y=-41 处创建单向平面。仅在拥有飞行权限时生效，只阻挡向下移动。 |
| 取消减速 | 移除使用盾牌、弓、弩、三叉戟、望远镜、山羊角、食物和饮用物品时造成的移动减速，并移除攀爬时的水平速度限制。 |
| 取消史莱姆弹跳 | 阻止史莱姆块让玩家弹跳。 |
| 矿车中保持方向 | 当前乘坐的矿车转向时，将变化应用到玩家视角。 |
| 空中上台阶 | 空中碰到小台阶或边缘时允许玩家执行上台阶处理。 |
| 自动下台阶 | 向可到达的较低地面移动时，允许平滑受控地下台阶。 |
| 步高 | 设置最大步高。 |
| 下蹲步高 | 设置下蹲时使用的最大步高。 |
| 修改跳跃高度 | 使用配置的目标跳跃高度覆盖本地玩家的跳跃力度。 |
| 目标跳跃高度 | 保存的目标跳跃高度，单位为方块。跳跃力度会在运行时根据该高度和玩家重力计算。 |
| 无限跳跃 | 允许玩家在空中无限次跳跃。 |
| 跳跃数量 | 设置落地前可执行的总跳跃次数。设置为 1 可关闭额外跳跃。 |
| 启用二段跳冷却 | 限制两次额外空中跳跃之间必须间隔指定的游戏刻。 |
| 二段跳冷却时长 | 设置两次额外空中跳跃之间必须间隔的游戏刻数。最小值: 0。 |
| 郊狼时间 | 从边缘走出或掉落后，仍可在指定 tick 内执行一次地面跳跃。最小值: 0。 |
| 延迟下坠时间 | 玩家从方块边缘踩空后，在指定 tick 数内保持高度。 |

### 自动问候

| 功能 | 说明 |
| --- | --- |
| 自己入服时问候 | 自己加入服务器后，依次发送配置的问候语。 |
| 他人入服时问候 | 其他玩家加入时，按黑白名单规则判断是否发送问候语。 |

消息支持 `@player`、`@UUID`、`@X`、`@Y`、`@Z`、`@health` 和 `@level` 占位符。

### 自动登录

| 功能 | 说明 |
| --- | --- |
| 启用自动登录 | 加入此服务器后，使用保存的密码执行登录。需要先为此服务器保存密码。 |
| 设置或修改密码 | 输入新密码后保存。进入页面时不会填充密码；留空会保留已有密码。保存后输入框会清空。 |
| 清空保存的密码 | 立即删除此服务器本地保存的密码。没有保存密码时此按钮不可用。 |
| 删除此服务器的登录配置 | 立即移除此服务器条目及其保存的密码和启用状态。 |

密码会在设备上加密保存，并且保存后不会再次显示。

### 我是谁

| 功能 | 说明 |
| --- | --- |
| 显示自己的名牌 | 在第三人称或自由相机视角中显示本地玩家名牌。 |
| 窗口标题显示名字 | 在 Minecraft 窗口标题中加入玩家名。 |

### 禁用纹理随机旋转

| 功能 | 说明 |
| --- | --- |
| 启用 | 禁用基于位置随机选择的方块模型变体，例如随机纹理旋转。 |
| 取消随机偏移 | 移除草、竹子等方块的随机视觉位置偏移。 |
| 保留碰撞方块偏移 | 保留有非空碰撞体积方块的视觉偏移。 |

### 飞行速度修改器

| 功能 | 说明 |
| --- | --- |
| 启用 | 启用飞行速度倍数调整。 |
| 速度最大值 | 保存的临时飞行速度倍数上限。最小值为 1.00 倍，建议设置在 100.00 倍以内。 |
| 速度最小值 | 临时飞行速度倍数下限。支持范围: 0.00 倍到 1.00 倍。 |
| 速度默认值 | 首次调整以及启用“每次调整前重置”时使用的保存值。最小值为当前速度最小值，最大值为当前速度最大值。 |
| 调整前重置 | 启用后，每次按下调整键都会先重置为配置的默认倍数；禁用后会保留上一次调整后的倍数。 |
| 滚轮倍数步长 | 控制每一个鼠标滚轮单位执行多少次非线性倍数调整操作。 |
| 应用于其他移动 | 同时将当前倍数应用于客户端主导的其他移动。 |

### 船只优化

| 功能 | 说明 |
| --- | --- |
| 解除视角限制 | 移除原版乘船时的 180 度水平视角限制，使视角可以完整旋转一周。 |
| 跟随视角 | 使船只始终跟随视角方向。左右移动键改为水平侧移，不再用于船只转向。 |
| 摄像机自动回正 | 未开启跟随视角时，若 1.5 秒没有移动摄像机，将摄像机平滑回正并居中。 |
| 方向快捷键 | 启用四个船只方向快捷键: 上键吸附到最近的合法方向，下键转向正后方，左键或右键转到对应一侧的下一个合法方向。 |
| 锁定到对角线方向 | 启用时，合法方向为所有 45 度倍数；关闭时，仅使用东、南、西、北四个正方向。 |
| 速度提升修复 | 使船只无论在地面、液体中、水下还是空中，始终使用蓝冰的速度。 |
| 防止下沉 | 船只位于水下时，将上浮速度固定为每秒 2.4 格。 |
| 船只步高 | 设置船只移动时可直接跨越的最大高度，范围为 0.0 到 10.0 格。 |
| 启用手刹 | 驾驶船只时，按住跳跃键设置一个减速。 |
| 启用弹射起步 | 若启用，松开手刹后，会根据手刹按住的时长增加一个推力。 |
| 启用横向摩擦力 | 为船只的横向移动施加额外摩擦力。 |

### 实体高亮

| 功能 | 说明 |
| --- | --- |
| 实体分组 | 设置可攻击生物、掉落物、动物、怪物或全部实体的高亮。具体实体规则优先于普通分组规则。 |
| 实体类型 | 按实体类型单独设置高亮和颜色。掉落物由物品高亮功能处理。 |

### 自动瞄准

| 功能 | 说明 |
| --- | --- |
| 自动瞄准模式 | 控制何时锁定目标；目标离开当前实体攻击范围后会停止瞄准。 |
| 结束瞄准时恢复视角 | 记录开始自动瞄准前的视角，并在目标失效或锁定结束时按所选条件恢复。 |
| 最大自动攻击距离 | 自动瞄准仅锁定此距离内的生物。实际有效范围同时受当前主手物品攻击范围限制。距离按玩家视点到目标碰撞箱的最近位置计算。 |
| 高亮目标 | 为当前自动瞄准锁定的目标显示发光轮廓。 |
| 目标高亮颜色 | 设置自动瞄准目标发光轮廓的颜色。 |
| 自动攻击 | “攻击冷却结束后”会等待完整攻击冷却后再叠加延迟；“是”只应用设置的延迟。首次选中和切换目标也会应用延迟。 |
| 自动攻击延迟 | 自动攻击前等待的游戏刻数，首次选中和切换目标时同样生效。 |

### 客户端伪解除限制

| 功能 | 说明 |
| --- | --- |
| 去除客户端方块交互距离限制 | 扩大本地客户端的方块交互范围。服务器仍可能拒绝过远交互。 |
| 去除客户端实体交互距离限制 | 扩大本地客户端的实体交互范围。服务器仍可能拒绝过远交互。 |
| 去除客户端挖掘方块速度 | 让本地客户端按瞬间破坏计算方块挖掘。服务器仍可能校正结果。 |

多人游戏服务器仍可能拒绝或校正不符合其规则的操作。

### 其他功能

| 离开当前世界 | 使用一个按键离开当前世界 |

## 默认按键

| 按键 | 功能 |
| --- | --- |
| V | 切换客户端飞行 |
| B | 切换禁止飞行 |
| 左 Alt + 鼠标滚轮 | 修改飞行速度 |
| I | 切换保持玩家高亮 |
| TAB | 按住高亮玩家 |
| F8 | 切换隐藏密码 |
| 反引号 (`) | 离开当前世界 |
| 方向键 | 启用方向快捷键后控制船只方向 |

## 命令

| 命令 | 说明 |
| --- | --- |
| `/wc autologin login` | 尝试使用当前服务器保存的登录信息 |
| `/wc findmob` | 查找指定类型的已加载实体 |
| `/wc findblock` | 查找指定类型的已加载方块 |
| `/get` | 添加幽灵物品 |
| `/i` | 显示当前玩家身份 |
