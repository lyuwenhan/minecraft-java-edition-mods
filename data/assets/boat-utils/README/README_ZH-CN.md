# Boat Utils (船只实用工具)

一个客户端 Fabric 模组，为船只提供可配置的视角与移动功能。

**注意: 本项目与 [OpenBoatUtils](https://modrinth.com/mod/openboatutils) 没有任何关联。如果你要找的是该项目，请确认你访问的是[正确的项目页面](https://modrinth.com/mod/openboatutils)。**

## 功能

- 解除原版乘船时的视角旋转限制
- 使船只立即跟随鼠标控制的视角方向
- 启用跟随视角后，将左右移动键从转向改为水平侧移
- 提供四个可配置的船只方向快捷键
- 将船只方向固定到四个正方向或所有 45 度方向
- 使用上、左、右方向快捷键时，将船只居中到当前方块
- 使用方向快捷键后清除船只的移动与转向惯性
- 使船只使用蓝冰的摩擦系数
- 在水下以每秒 2.4 格的固定速度上浮，防止船只下沉
- 开启防止下沉后，允许水下上船并阻止原版强制下船
- 提供可配置的船只步高
- 提供手刹和可选的弹射起步功能

## 配置

可以通过 Mod Menu 打开模组配置界面。

配置界面包含以下选项：

- 解除视角限制
- 跟随视角
- 启用方向快捷键
- 包含 45 度方向
- 速度提升修复
- 防止下沉
- 启用手刹
- 启用弹射起步
- 船只步高

### 解除视角限制

移除原版乘船时的 180 度水平视角限制，使视角可以完整旋转一周。

### 跟随视角

使船只立即朝向鼠标控制的视角方向。

启用后：

- 前进和后退会相对于当前视角方向移动
- 左右移动键改为水平侧移，不再旋转船只

关闭后，船只恢复原版转向操作。

### 方向快捷键

提供四个船只方向快捷键。仅在本地玩家实际控制船只，并且当前没有打开菜单或其他界面时生效。

默认按键如下：

|按键|操作|
|---|---|
|上方向键|固定到最近的合法方向|
|下方向键|精确转到当前方向的正后方|
|左方向键|向左转到下一个合法方向|
|右方向键|向右转到下一个合法方向|

可以在 Minecraft 的按键设置中修改这些按键。快捷键位于 **船只方向快捷键** 分类下。

执行任意方向快捷键后，模组会：

- 清除船只的水平和垂直速度
- 清除船只的转向旋转惯性
- 清除当前已经积累的手刹状态

执行上、左、右方向快捷键时，还会将船只的 X 和 Z 坐标移动到当前方块的中心。

执行下方向快捷键时只改变方向，不会将船只居中。

#### 合法方向

**包含 45 度方向**选项决定哪些角度属于合法方向：

- 开启：所有 45 度倍数的方向均为合法方向，共八个方向
- 关闭：仅东、南、西、北四个正方向为合法方向，角度间隔为 90 度

此选项默认开启。

### 速度提升修复

使船只始终使用蓝冰的摩擦系数。

### 防止下沉

船只位于水下时，模组会将其上浮速度固定为每秒 2.4 格。

开启此选项后，模组还会：

- 阻止原版水下强制下船计时将乘客弹出
- 允许玩家在水下登上船只

这些骑乘行为由服务端控制。单人游戏中预计可以生效，但远程服务器可能拒绝或纠正这些行为。

### 船只步高

设置船只移动时可直接跨越的最大高度。

可设置范围为 0.0 到 10.0 格。

### 手刹

开启**启用手刹**后，驾驶船只时按住跳跃键即可使用手刹。

手刹会逐渐降低船只的水平移动速度，同时保留垂直方向的移动速度。

#### 弹射起步

同时开启**启用弹射起步**后，在按住前进键的情况下松开手刹，会根据手刹按住的时长，向船只当前朝向施加一次向前加速。

手刹按住时间越长，加速效果越强，直到达到最大加速速度。

## 多人服务器风险

本模组会修改客户端主导的船只移动。服务器可能纠正、拒绝或标记这些移动行为。

仅应在服务器规则允许时使用。模组作者不对使用本模组造成的警告、踢出、封禁或其他处罚负责。
